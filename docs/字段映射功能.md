# 字段映射功能使用说明

## 功能概述

在**数据湖抽取生成数据集**时，支持使用字段映射模板将多个字段拼接为一个 `text` 字段，适用于：

- **QA 对数据集**：`question` + `answer` → `text`
- **客服对话**：`user_query` + `assistant_reply` → `text`
- **结构化转非结构化**：任意字段组合成 LLM 训练文本

**适用数据类型**：所有表格类数据
- 数据库表（PostgreSQL、MySQL、GoldenDB 等）
- CSV / TSV 文件
- Excel 文件（.xlsx、.xls）
- JSONL / JSON 文件

## 使用位置

**数据湖详情页 → 勾选快照 → 抽取生成数据集**

注意：字段映射功能在**数据湖抽取**环节，不在采集任务环节。

## 使用步骤

### 1. 进入数据湖详情页

路径：**数据治理 → 数据湖 → 点击某个数据湖**

### 2. 选择快照

在「文件列表」中勾选一个或多个快照（必须包含至少一个**表格类快照**）

**表格类快照**包括：
- `database` 类：数据库采集的数据
- `tabular` 类：CSV、TSV、Excel、JSONL 等文件

### 3. 点击「抽取生成数据集」

右上角按钮会显示已选快照数量

### 4. 填写表单

弹窗中包含以下字段：

- **数据集名称**（必填）
- **描述**（可选）
- **字段映射模板**（可选，仅当选中表格类快照时显示）

### 5. 填写字段映射模板

**模板语法**：使用 `{字段名}` 占位符

**示例**：
```
用户提问：{question}，客服回答：{answer}
```

### 6. 提交

点击「确定」，系统会：
1. 从快照中抽取原始数据
2. 应用字段映射（仅对 database 类快照）
3. 生成新数据集
4. 跳转到数据集详情页

## 数据转换示例

### 输入（数据湖快照）

假设数据湖中有一个来自 PostgreSQL 的快照：

```json
{
  "id": 1,
  "question": "农业银行手机银行单日转账限额多少？",
  "answer": "农业银行手机银行默认单日累计转账限额10000元（具体以签约时约定为准），可通过网点风险评估后申请提升限额。"
}
```

### 模板

```
用户提问：{question}，客服回答：{answer}
```

### 输出（数据集记录）

```json
{
  "id": 1,
  "question": "农业银行手机银行单日转账限额多少？",
  "answer": "农业银行手机银行默认单日累计转账限额10000元（具体以签约时约定为准），可通过网点风险评估后申请提升限额。",
  "text": "用户提问：农业银行手机银行单日转账限额多少？，客服回答：农业银行手机银行默认单日累计转账限额10000元（具体以签约时约定为准），可通过网点风险评估后申请提升限额。",
  "source_version": "source_v20260703_01_postgresql",
  "db_schema": "public",
  "db_table": "qa_bank"
}
```

注意：
- 原字段保留（`id`、`question`、`answer`）
- 新增 `text` 字段
- 血缘字段自动注入（`source_version`、`db_schema`、`db_table`）

## 技术实现

### 后端流程

```
用户提交模板
    ↓
ExtractToDatasetRequest.field_mapping
    ↓
lake_extract.extract_to_new_dataset()
    ↓
遍历每个快照:
  - extract_from_lake_snapshot() 读取原始记录
  - 如果是 database 类快照 + 有模板
    → _apply_field_mapping_transform() 应用映射
  - add_table_member() 落地为数据集表成员
    ↓
返回新数据集
```

### 字段映射转换

使用 data-juicer 的 `python_lambda_mapper` 算子：

1. 正则提取模板中的 `{字段名}` 占位符
2. 生成 lambda 字符串：
   ```python
   lambda row: {
       **row, 
       'text': f'用户提问：{row.get("question", "")}，客服回答：{row.get("answer", "")}'
   }
   ```
3. 调用 `engine.filter_records()` 执行算子

### 条件判断

- **仅对 database 类快照生效**：文件类（图片、文档等）无固定 schema，跳过
- **前端条件渲染**：仅当选中的快照中至少有一个 `dataCategory === 'database'` 时，才显示字段映射表单

## 限制与注意事项

1. **仅表格类快照生效**
   - **database 类**：采集任务从数据库拉取的数据
   - **tabular 类**：CSV、TSV、Excel、JSONL 等表格文件
   - 其他类型（图片、音频、视频、文档）会跳过字段映射

2. **字段名大小写敏感**
   - `{Question}` 和 `{question}` 是不同的字段

3. **原字段保留**
   - 映射不会删除原字段
   - 只新增 `text` 字段

4. **模板长度限制**
   - 前端限制 500 字符

5. **字段不存在时**
   - 自动填空字符串（`row.get("字段", "")`）
   - 不会报错

6. **混合快照**
   - 如果选中的快照既有表格类又有媒体类
   - 仅表格类会应用字段映射
   - 媒体类正常抽取（不受影响）

## 常见问题

### Q：字段映射在哪个环节生效？

A：在**数据湖抽取生成数据集**环节，不是采集任务环节。

### Q：如何知道快照有哪些字段？

A：数据湖详情页可以预览快照内容，查看字段列表。或者参考原始数据源的表结构。

### Q：可以对文件类快照使用字段映射吗？

A：可以！只要是**表格类数据**都支持：
- ✅ 数据库表（database 类）
- ✅ CSV、TSV 文件（tabular 类）
- ✅ Excel 文件（tabular 类）
- ✅ JSONL、JSON 文件（tabular 类）
- ❌ 图片、音频、视频（无字段结构）
- ❌ PDF、Word、PPT 文档（非结构化）

### Q：选中多个快照，每个快照的字段不一样怎么办？

A：模板会应用到所有 database 类快照。如果某个快照缺少模板中的字段，会自动填空字符串。

建议：如果快照的字段结构差异很大，分批抽取成不同的数据集。

### Q：原字段会被删除吗？

A：不会。字段映射只新增 `text` 字段，所有原字段都保留。

### Q：可以用多行模板吗？

A：可以。模板支持换行符，输出的 `text` 字段会保留换行。
